# german-fuhrerschein-notes

Visual study notes and diagrams for the German Führerschein (driving licence) theory exam.

Topics are covered as Markdown notes (`.md`) and PlantUML diagrams (`.puml`) with exported PNGs.

All important theory exam notes are organised here — hopefully useful to others too. The notes are split into two folders: `md/` contains written notes that help answer exam questions, and `puml/` contains diagrams rendered as PNGs (each in its own subfolder). The `.puml` files are the PlantUML sources used to generate the diagrams and can be ignored.

If you spot anything incorrect or missing, feel free to let me know.

## Reference

[questions_with_numbers.md](md/questions_with_numbers.md) — A collection of all exam questions where the answer is a number (speeds, distances, weights, durations, etc.).
