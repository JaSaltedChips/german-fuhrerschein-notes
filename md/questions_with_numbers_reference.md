# Key Numbers — German Führerschein Theory Reference

---

## Speed Limits

| Speed | Where / Condition |
|---|---|
| **30 km/h** | Bicycle zone (Fahrradzone) |
| **50 km/h** | Inside built-up areas (innerorts) — default |
| **50 km/h** | Motorway in fog with visibility under 50m — hard limit |
| **50 km/h** | Maximum after turning (video question) |
| **50 km/h** | Maximum speed with snow chains |
| **80 km/h** | Car with trailer outside built-up area |
| **80 km/h** | Combination vehicle (≤3.5t) with trailer without 100 km/h approval on motorway |
| **100 km/h** | Outside built-up areas (außerorts) — default for cars and motorcycles |
| **100 km/h** | Combination vehicle (≤3.5t) with 100 km/h approval on federal highway (not motorway) — still capped at 80 km/h on motorway without approval |
| **130 km/h** | Motorway advisory speed (Richtgeschwindigkeit) — recommended, not a hard limit |
| **>60 km/h** | Minimum speed capability required to use the Autobahn — must be entered in registration certificate Part 1 |

## Stopping & Parking Prohibitions

| Distance | Rule |
|---|---|
| **5m** | Before and after intersections and junctions — no parking |
| **5m** | Before pedestrian crossings — no stopping |
| **5m** | Before St. Andrew's Cross (Andreaskreuz) inside built-up area |
| **8m** | Before a junction where a cycle path runs alongside the carriageway |
| **10m** | In front of traffic lights if signal would be concealed by the vehicle |
| **10m** | Before and after level crossings (Bahnübergänge) |
| **10m** | From fire hydrants — no parking |
| **15m** | Before and after bus/tram stops — no parking |
| **50m** | Before St. Andrew's Cross outside built-up area |
| **3m** | Minimum gap between parked vehicle and solid lane boundary line |
| **1.5m** | Minimum pedestrian clearance when parking on designated footpaths |
| **3 min** | Maximum stopping time at a bus stop (without obstructing buses) |

| Road user | Inside built-up area | Outside built-up area |
|---|---|---|
| Cyclists, e-scooters, pedestrians, motorcyclists | **1.5m** | **2.0m** |

## Safe Following Distance

| Speed | Minimum distance |
|---|---|
| **100 km/h** | **50m** (half the speedometer reading in metres) |

**Long vehicle combinations (>7m):** must leave enough gap in front for an overtaking vehicle to pull in — rule applies when combination exceeds **7m**.

## Stopping Distances & Formulas (Faustformeln)

| Formula | Name |
|---|---|
| **(speed ÷ 10) × 3** | Reaktionsweg — reaction distance |
| **(speed ÷ 10)²** | Bremsweg — normal braking distance |
| **(speed ÷ 10)² ÷ 2** | Gefahrenbremsung — emergency braking distance |
| **Reaktionsweg + Bremsweg** | Anhalteweg — total stopping distance |

**Examples:**

| Speed | Reaction distance | Braking distance | Total stopping distance |
|---|---|---|---|
| **50 km/h** | 15m | 25m | **40m** |
| **100 km/h** | 30m | 100m | **130m** |

> Doubling speed makes braking distance **4× longer** (not 2×) — because braking distance is proportional to speed squared.

> Reaction distance is always included — the car travels at full speed for ~1 second before brakes engage.

**Sichtfahrgebot:** on a narrow road with 50m visibility, maximum stopping distance must be **25m** — drive at 50 km/h or less.

## Fog & Visibility

| Value | Rule |
|---|---|
| **50m** | Rear fog lamp (Nebelschlussleuchte) becomes mandatory below this |
| **50 km/h** | Maximum speed on motorway when visibility is under 50m |

> If visibility is dangerously low: pull off the road, switch off driving lights, leave only parking lights on — so you are not mistaken for a moving vehicle.

## Trailer Vertical Load (Stützlast)

| Value | Rule |
|---|---|
| **4%** of actual trailer gross weight | Minimum vertical load on tow ball |
| Car documents | Maximum vertical load — found in registration certificate Part 1 and owner's manual |

> Example: trailer gross weight 600 kg → minimum Stützlast = 4% × 600 = **24 kg**
> Too little → trailer sways (Schlingern). Too much → overloads car's rear axle.

| **3mm** | Recommended minimum for summer tyres |
| **4mm** | Recommended minimum for winter tyres |

## Blood Alcohol Concentration (BAC)

| Limit | Who it applies to |
|---|---|
| **0.0‰** | New drivers during Probezeit and all drivers under 21 — zero tolerance |
| **0.5‰** | General limit for all other drivers |
| **1.6‰** | Threshold requiring compulsory MPU (medical-psychological assessment) |

> Even below 0.5‰, a driver can be penalised if there is clear evidence of impaired driving.

## Roadworthiness Test (Hauptuntersuchung)

| Interval | Condition |
|---|---|
| **24 months** | Standard interval after the initial test period |

> A 3-year-old car with a new test certificate must be retested within **24 months**.
